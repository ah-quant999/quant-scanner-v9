# quant-scanner-v9

九宝量化 v9 · 只做两件事：**① 判断大盘走势 ② 选出未来收益率最高的股**（v8 精简重建，留精不留多）

## 只有两个页面

| 页面 | 回答的问题 | 卡片 |
|---|---|---|
| 📊 大盘 | 现在大盘什么情况 | 指数快览 · 大盘资金（主力净额）· 平均股价（全市场位置） |
| 🎯 选股 | 我能买哪些收益率高的股 | 今日结论 · 最终推荐（Top5 + 候选池）· 证据链（榜单健康度 + 样本外验证） |

其余观测类视图（涨停热力、板块资金榜、板块强度榜、龙虎榜、ETF 三合一、概念资金热力、行业树图、运维页…）**一律留在 v8**，不进 v9。

## 与 v8 的关系

- v8 代码冻结不再改；其数据链继续跑。
- v9 只展示、不生产：`.github/workflows/sync_data.yml` 定时从 v8 Pages 拉 6 个 `data/*.js`（约 100KB）后提交，触发 `deploy.yml` 发布 Pages。
- 铁律：数据一律 `window.X` 注入，禁止 `fetch('../data/...')`；任何数据缺失一律明示「未到位」，绝不用陈旧数据冒充当日。
- 质量闸：榜单 `validity≠ok` 或 `max_score<10` ⇒ 只出「候选观察」，不摆伪 Top5。
